Replication data for:

Hamann, David/Jäckle, Sebastian (2025): 
Personality Traits and Voting Behaviour: A Tale of Open-Minded Switchers and Agreeable Government Loyalists
in: Politisch Vierteljahresschrift

The replication data includes

1) This ReadMe File
2) "Personality Traits and Vote Switching_v2.r": R-code replicating all figures and tables from the article (except for Figure 4, see below)
3) "Figure 4.do": Stata code replicating Figure 4 
4) a folder "data" including a dataset with individual data from three waves from the Politikpanel Deutschland Survey, 
   June 2022/January 2023/October 2023 (https://www.politikpanel.uni-freiburg.de/): "PPD_Waves7-9.dta" 
5) a folder "figures" in which all figures from the article will be saved.  
6) a folder dump in which intermediate results and results not presented in the article are saved (can be deleted after the estimation).

In order to replicate the results, please follow the following procedure:
	a) Open "Personality Traits and Vote Switching.r" and set working directory to the "Replication" folder (line 25)
	b) Run the complete R-code (--> 2 new Stata datasets will be saved in the "data" folder) 
	c) Open "Figure 4.do" and set the path to the "Replication" folder (see line 3)   
	d) Run the complete Stata-code
